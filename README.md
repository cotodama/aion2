# アトレイア情報局 — AION2公開PoC

公開先: https://cotodama.github.io/aion2/

site.zipには生成済みHTML・CSS・JavaScript・必要画像のみを収録。原稿・取材記録・編集履歴・認証情報・別系統の試作は含めません。

PoCのため検索エンジン向けにnoindexを指定しています。

Cloudflare Pagesのビルドコマンド: `unzip -q site.zip -d public`、出力先: `public`。GitHub Pagesと同一成果物を配信します。
